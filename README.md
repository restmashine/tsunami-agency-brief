# Цунами — задача для разработчиков

Публичная страница: https://restmashine.github.io/tsunami-agency-brief/

Назначение: короткая страница для первого разговора с разработчиком и оценки проекта.
Файлы: `index.html`, `brief.md`, `proposal-template.md`, `current-web.png`, `.nojekyll`,
`frames/` (15 проверенных кадров), `previews/` (9 экранов демо), `prototypes/` (H9, H10, H11).
GitHub Pages публикует ветку `main`, каталог `/`.

Страница показывает действующий сайт, ссылки текущих приложений, наблюдения
о проблемах пути, желаемые изменения, ожидаемый результат и вопросы к исполнителю.
Все разделы открыты на одной странице и проходятся обычной вертикальной прокруткой.
Рядом с проблемами — раскадровки, ниже — гипотезы и экраны существующих прототипов.
Нажатие увеличивает кадр; «Попробовать прототип» открывает кликабельное демо
поверх лендинга. Есть копирование ссылки, печать и подробный бриф.
Снимок витрины снят с публичного сайта 08.10.2026
и проверен перед публикацией. Предложение отправляется в ответ на сообщение,
в котором разработчик получил ссылку; форма сбора данных отсутствует.

В этой копии нет внутренних финансовых показателей, аналитических выгрузок,
ответов поставщиков, переписки и ссылок на внутренние материалы.
Кадры с личными адресами и телефонами исключены. В прототипах вымышленные
данные и условия; они не создают заказы, не проводят оплаты и не отправляют ввод.
