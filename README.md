# Цунами — бриф для агентств

Публичная страница: https://restmashine.github.io/tsunami-agency-brief/

Назначение: запрос сопоставимой оценки сайта и приложений доставки.
Файлы: `index.html`, `brief.md`, `proposal-template.md`, `.nojekyll`.
GitHub Pages публикует ветку `main`, каталог `/`.

Страница содержит контекст проекта, функциональные требования, интеграции,
миграцию и формат коммерческого предложения. Предложение отправляется в ответ
на сообщение, в котором агентство получило ссылку; форма сбора данных отсутствует.

В этой копии нет внутренних финансовых показателей, аналитических выгрузок,
ответов поставщиков, переписки и ссылок на внутренние материалы.
